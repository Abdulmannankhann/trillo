# 🧳 Trillo — Responsive Booking App UI

A responsive travel booking interface built as part of my frontend learning journey. This project focuses on mastering modern layout techniques using Flexbox and SCSS while building a clean, app-style UI.

---

## 📌 About The Project

Trillo is a fictional all-in-one booking platform UI for hotels, flights, car rentals, and tours. The goal of this project was to practice advanced Flexbox layouts, component structuring, and responsive design by recreating a complex interface from scratch.

This project was created purely for learning and practice purposes.
